# Chapter 7 — Error Propagation

## Core claim
A mistaken interpretation can become infrastructure for later reasoning.

## Material on the wall
- Observation A → interpretation B → conclusion C → prediction D.
- If B is wrong, C and D can still appear coherent.
- Later conclusions may become assumptions for still later conclusions.
- Eventually the original mistake becomes buried.
- **Knowledge isn’t simply cumulative. It’s recursive.**
- Recursive loop: observation → interpretation → relationships → model → predictions → new observations → reinterpretation.
- Each cycle can amplify truth or error.
- Engineering analogy: bad calibration/reference value contaminates every downstream calculation.

## Questions
- Find an example where a small foundational measurement/assumption generated a large coherent error.
